Resolución del ejercicio N°21de la unidad 2 de programación 2.
Este programa simula un sistema orientado a objetos para gestionar de manera unificada diferentes dispositivos de almacenamiento, utilizando polimorfismo para procesar operaciones de escritura y lectura con validaciones de capacidad.

Clases e Interfaz Utilizadas
DispositivoAlmacenamiento (Interfaz): Define los contratos estándar de lectura y escritura de datos.
DiscoDuro: Implementa la interfaz simulando un disco magnético con atributos de velocidad de rotación y control de espacio.
UnidadSSD: Implementa la interfaz representando un disco de estado sólido con alta velocidad de transferencia.
MemoriaUSB: Implementa la interfaz simulando un dispositivo portátil con especificación de versión USB.
